Stoipath

A whole-slide image viewer for pathology research and education, built on a browser engine that measures its own speed and sharpness. These are its published pages.

  • No patient data. Every slide is public, de-identified research data. None of these pages is a medical device or for diagnosis.
  • Intended for open-source release; licence proposed, pending UT OTC approval.
  • Built by AI agents with human gate review by the project owner. No human pathologist has reviewed the teaching cases yet.
  • Use Chrome or Edge on a computer for the practice report until its Safari colour check is done (on iPhone and iPad every browser uses Safari's engine).

About these pages

Release status

Stoipath is intended for open-source release; licence proposed, pending UT OTC approval. Proposed licence for the software: Apache-2.0 (proposed; pending UT OTC approval). The licence of the teaching text is to be confirmed.

Data

Slides from CAMELYON16 and CAMELYON17 (CC0 1.0; Computational Pathology Group, Radboud University Medical Center, Nijmegen, with partner hospitals) and from the OpenSlide test data (CC0 1.0, except one sample that its source lists as “distributable”).

Privacy

No patient data. Nothing you type or do on these pages is sent anywhere; progress stays in your browser until you export it. The practice report reads slide tiles from the public CAMELYON17 bucket (Amazon S3), which sees your network address, as any web host does.

How it was built

Built by AI agents with human gate review: the project owner reviews at defined gates. Reviews in the project's documents described as pathologist-educator, accessibility or engineering reviews were done by AI agents in those roles, not by human professionals.
