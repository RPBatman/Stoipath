# Research notes

Supporting research notes for the Stoipath WSI viewer plan, **dated 2026-10-24** (the gap-fill notes were written the same day, after the first ten, to close questions the proposals and judges raised). They are the evidence base the architecture proposals, the recommended architecture and the plan sections cite as `research/NN` or `note NN`; they are kept as written. Each note carries its own evidence legend — **[verified]** (primary source read that day), **[measured]** (run on the planning machine), **[model]**, **[estimate]**, **[unverified]**, **[snippet]** (search-engine extract only, page unreachable from the sandbox) — and anything **[unverified]** is a planning assumption to be re-checked before it drives a decision. Twenty-four load-bearing claims drawn from these notes and the architecture were re-checked by the [claims-verification pass](../verification/README.md); where a number was adjusted, the plan sections and the recommended architecture carry the corrected value and the notes keep the original.
