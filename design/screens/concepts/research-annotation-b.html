Design rationale · concept B “Workbench” · what to look at, trade-offs, contract map

What this concept does differently

Concept B treats the research workspace as a bench, not a dashboard: two persistent, resizable docks flank a large canvas, and every panel the three pillars need (cohort, slides, layers, inspector, annotations, model, channels, export) has a fixed home that is either visible or exactly one click or keystroke away. The command palette is not a hidden power feature but the always-visible search field in the top bar (CtrlK): it indexes commands, slides, layers, classes and bookmarks and shows every shortcut, so the keymap is learned by using it. Learnability and completeness are bought with chrome; the concept's whole discipline is spending that chrome without breaking P1 (canvas ≥ 70 %) or P2 (no layout during gestures).

Key choices

  1. Library (left) and Context (right) are different kinds of panel. The Library answers “what am I looking at and what is on it” (Cohort, Slides, Layers); the Context dock answers “what is selected and what can I do to it” (Inspector, Annotations, Model, Channels, Export). The split is the QuPath / VS Code habit researchers already have; panels never move between sides, so muscle memory holds across surfaces.
  2. Panel switchers live in the tool rail. The three Library icons at the top of the rail open and pin the Library tabs, so the rail is the one fixed column and the Library can collapse to zero width without the switchers disappearing. Counts on the icons (3 slides, 5 layers) keep the state readable when the panel is closed.
  3. Default at-rest state is chosen per surface to pass P1. 4K: both docks open (canvas ≈ 77 %). 1920 × 1080: Context open, Library collapsed (≈ 74 %); pinning the Library drops the share to ≈ 61 % and the demo readout says so honestly, because the user chose it. Laptop 1440 × 900: both docks are drawers over the canvas edge, and the Context tabs stay visible as a 36 px panel strip so completeness survives the collapse (≈ 85 %). Tablet portrait: rail → 72 px bottom bar, docks → bottom sheets ≤ 40 %. Phone: point and measure tools only, everything else in the palette.
  4. Resizable by keyboard. Both dock resizers are focusable separators (←/→ in 16 px steps, 240–400 and 320–520 px); widths are fixed grid tracks, so a panel re-render never re-lays out the canvas.
  5. Outline first, heatmap on demand for the AI probability layer (principles §3.2); the pattern (dotted = metastasis, dashed = suspicious), not the hue, separates the AI outline from the user's own Tumor polygons, which share the Sienna class colour.
  6. Provenance is everywhere the output is. The layer row, the Model panel's job list and the Export manifest all show the same tuple {producer, version, inputHash, createdAt, regulatoryStatus}; nothing can be exported or accepted without it.
  7. Compare is a state, not a screen. C splits the canvas into two linked views with a sync segmented control (lock / affine / none) and a one-line registration status; / swaps to a curtain over one view. The controls sit at the top edge, outside the central 50 %.
  8. Widget chrome is the same shell with the docks removed: 36 px bar, rail collapsible behind one button, the palette field kept, and the strip reduced to the sharpness indicator plus the Synced with Python chip. The round-trip is visible, not assumed.

Trade-offs and known weaknesses

  • Chrome appetite on laptops is real. At 1440 × 900 the drawers cover 320 px of canvas edge while open; a researcher who keeps the Annotations list open all day sees a 56 % canvas. The mitigation is the panel strip plus \ focus mode, not a smaller panel.
  • Two docks mean two places to look. Concept A-style single-dock designs are simpler to learn in the first minute; B bets that researchers run long sessions where fixed homes beat fewer regions.
  • Five Context tabs exceed the base tab width at 320 px (they scroll); the count badges help, but the Model and Channels tabs may deserve icons at the minimum width.
  • The pinned Library at 1920 fails P1 by design. Judges should decide whether “user-chosen” is an acceptable exception or whether pinning should force the Context dock to its 320 px minimum.
  • Proposed bindings \ (focus mode) and ⇧G (channel grid) are not in principles §4.5 and are flagged as Design notes B-1 and B-2 below.
  • The tissue, nuclei, detections and channel renders are SVG stand-ins for GPU layers; the tile-error patches approximate “best resident ancestor” with a blur.

What judges should look at

  • Press CtrlK and type heat, ck, stroma, export: one field reaches a presentation toggle, a slide, a class and a panel. Press ? for the map.
  • Resize the window across 1600 px and 1080 px and watch the Context tabs become the panel strip, then the bottom bar; nothing disappears, it only moves.
  • Use the demo strip: Cold 4G, Offline pack, Tile errors and Dx refused each produce a named state with the §5 microcopy verbatim and a canvas that is never blank.
  • Toggle Simulate deuteranopia in the Annotations tab: the five classes stay distinguishable (palette ΔE00 ≥ 20 under deutan).
  • Switch the Library to Layers and flip Outline / Heatmap; then open Channels after selecting HTA7_tonsil_002 and press Grid view.

Design notes (conflicts flagged, choices made)

B-1 · \ “Focus mode” (hide / restore both docks) is a new unmodified binding, not in principles §4.5. Proposed for the registry; recoverable via the palette if rejected.
B-2 · ⇧G “Channel grid view” is new; G stays the HPF reticle. Proposed.
B-3 · The Library's default pinned state is per surface (open ≥ 3200 px, collapsed below). Principles §7 fixes a collapse order but not a per-surface default for a second dock; this concept proposes one and reports the canvas share.
B-4 · The AI probability layer's “Accept / Reject” exists in the RUO build as research events only (active-learning labels, FR-A5 fields); there is no write-back and no LIS surface, as the build matrix requires.
B-5 · The scale bar reads 100 µm at 20× (0.50 µm/px → 200 CSS px, inside the 80–200 px rule of §5.2) where the clinical brief uses 200 µm; the snapping rule, not the label, is what is fixed.
